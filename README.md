# YouTube Idea Scout

Searches YouTube overnight against a maintained list of niches/keywords and produces a morning report of video ideas worth considering.

## What it does

Runs on a schedule (overnight), searches YouTube for a set of keywords/niches Lee maintains, and writes out a local report so there's a ready-made idea list waiting each morning — instead of manually trawling YouTube for inspiration.
